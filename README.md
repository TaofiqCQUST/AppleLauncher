# Apple Launcher (Android TV)

হালকা, কোনো বাইরের লাইব্রেরি ছাড়া Android TV লঞ্চার।

- রিমোটের তীর কী দিয়ে নেভিগেশন, OK চাপলে অ্যাপ খুলবে
- OK বাটন চেপে ধরলে অ্যাপ ডকে পিন / আনপিন হবে (সর্বোচ্চ ৭টি)
- ঘড়ি, তারিখ ও শুভেচ্ছা বার্তা

## APK বানানো (GitHub Actions)
1. GitHub-এ নতুন repository খুলুন
2. এই ফোল্ডারের সব ফাইল আপলোড করুন (.github ফোল্ডারসহ)
3. Actions ট্যাবে "Build APK" চলবে (৩-৫ মিনিট)
4. শেষ হলে রান খুলে নিচে Artifacts থেকে AppleLauncher-APK ডাউনলোড করুন
